# MKG-utils

HTML完結型の雑多な便利ツール集です。

> [!NOTE]
> 各種ツールの作成にAIエージェントを使用しています。

## 動作環境

ブラウザさえあれば動作します。

動作においてインターネット環境は必要ありません。すべてローカルの動作で完結します。

## 使用方法

必要なHTMLファイルをローカルにダウンロードして、お使いのブラウザで開いてお使いください。

## 内容

### image_simple_animator.html

複数のコマを持つ画像を1つ読み込み、連番でアニメーションさせるツールです。

アニメーションが破綻していたり、座標がずれていないかを簡易的に確認する用途に使えます。

何かを編集する機能はありません。

### image_splitter.html

画像を1つ読み込み、それを横x,縦y個のピース(タイル画像)に分割し、zipファイルとして保存するツールです。

### image_tiler_mod.html

画像を複数読み込み、連番に並べて1つの画像にまとめるツールです。

並べる際は横方向に並べる個数を指定可能です。
縦方向はタイル数から自動計算されます。
また、足りない分は余白で埋められます。

ピースの画像の大きさが一致していない時は、それぞれ最も大きいものに合わせられます。
水平、垂直方向のアラインメントを指定可能です。

> [!NOTE]
> 同じ画像を複数回D&Dすることも可能です。
> この場合、1つの画像で複数個のタイリング（繰り返し）を作ることもできます。
