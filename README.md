# MKG-utils

雑多なHTML完結型の便利ツール集

## 動作環境

ブラウザさえあれば動作する。
すべてローカルの動作で完結し、Web環境は必要ない。

## 内容

### image_simple_animator.html

複数のコマを持つ画像を1つ読み込み、連番でアニメーションさせる。

アニメーションが破綻していたり、座標がずれていないかを簡易的に確認するツール。

何かを編集したり、ダウンロードする機能はない。

### image_splitter_mod.html

画像を1つ読み込み、それを横x,縦y個のピース(piece, タイル画像)に分割し、zipファイルとして保存できる。

### image_tiler_mod.html

画像を複数読み込み、連番に並べて1つの画像にまとめる。
並べる際は横方向に並べる個数を指定可能。縦方向はタイル数から自動計算される。足りない分は余白で埋められる。

ピースの画像の大きさが一致していない時は、それぞれ最も大きいものに合わせられる。
水平、垂直方向のアラインメントの指定も可能。

> [!NOTE]
> 同じ画像を複数回D&Dすることも可能。この場合、1つの画像で複数個のタイリング（繰り返し）を作ることもできる。
